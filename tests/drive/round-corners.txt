# Rounding the corners of a rectangle with the arc tool, SketchUp's way.
#
# Tony: "i was trying to make a rectangle have rounded corners using the arc
# tool in its corners but it seemed like i was always getting like a bubbled
# out corner unless i got the dimension just right."
#
# Click a point on each of the two edges near a corner, pull the middle in
# towards the corner until the arc turns magenta - TANGENT TO EDGE - then
# double-click: the first click puts the arc in, the second trims the square
# corner away.  A double-click near any other corner does the same again.
#
# What to look for: hsk-rc-tangent has a magenta arc, tangent into both
# edges, with TANGENT TO EDGE beside the pointer; hsk-rc-trimmed has that
# corner rounded with no square corner left behind it; hsk-rc-repeated has a
# second corner rounded to the same radius.
activate
wait 1000
key slash
type plan
key return
wait 1000
key slash
type clear
key return
wait 1000

# a rectangle, well clear of everything
key r
wait 300
at 400 250
click
at 800 550 500
click
wait 900

# on the left edge

wait 400

wait 300
