# Turning a face over from the right button.
#
# A single upright panel, seen from behind, so it shows the pale blue back
# that says a face is inside out.  Nothing in the drawing can tell the
# program which side of a loose wall is outside, so the person looking at it
# has to - which is what the menu on the select tool is for.
#
# What this proves: right-clicking picks the face under the cursor, the menu
# offers Reverse Face, and taking it turns the panel from blue to grey.

activate
wait 600

key slash
type fit
key return
wait 1500
shot /tmp/hsk-reverse-before.png

at 750 382

click right
wait 800

click
