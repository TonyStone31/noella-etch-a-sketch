# Reporting a problem

Use **Report a problem** in the help menu.  It takes a description, adds what
the program was doing - version, tool, view, and the last few things that
happened - and sends it.

Two things are asked for separately and neither is assumed:

* **a picture of the drawing area**, drawn by the program from what it has
  already rendered, so it shows only this window and nothing else on screen;
* **the drawing file itself**, which is off unless you turn it on, because it
  is your work.

Say no to either and the report still goes and is still useful.

If the program falls over, it writes a report next to itself and offers to
send it the next time it starts - again, only if you say so, and you can read
it first.
