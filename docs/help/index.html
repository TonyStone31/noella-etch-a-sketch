About this help

These pages are the same in the program and on the web. In the program, /manual opens them from a copy kept beside Heckers Sketch, so they are there without the internet once it has fetched them.

Click any picture or animation to see it larger - in its own window in the program, or a new tab on the web.

Light or dark. On the web the button at the top right switches between them: Auto follows whatever your phone or desktop asks for, and Light and Dark say so regardless. The choice stays in that browser. Opened from inside the program there is no button, because the pages simply wear whatever theme the program is wearing.

Every picture is taken on an empty sheet by driving the program itself, with the smallest thing that shows the tool. A few pages still say "not taken yet" where a picture will go; shots/NEEDED.md lists them.
