Rotate

Turn things about a point.

Keyboard: Q

How to use it

  1. Click the center, then a point to measure from, then swing to the angle.
  2. Or type it - 34.1 for degrees, or 8:12 for a slope.
  3. The arrow keys pick the plane it turns in. Ctrl leaves a copy.
