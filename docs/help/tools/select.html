Select

Pick what you want to work on.

Keyboard: Space

How to use it

  1. Click a thing to pick it.
  2. Drag a box to pick several.
  3. Ctrl adds to what is picked, Shift toggles, Ctrl+Shift takes away.
  4. Right-click for what can be done to it - turn a face over, centre it on the origin, plan from here, erase.
