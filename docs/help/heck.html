Heck

The drawing as text you can read - and type.

Experimental. Everything on this page works today and is changing every few days. The words may change; a drawing saved as Heck now may need a small edit later. The .hsk file the program saves is still the old format; Heck is what /source shows, and what it reads back when you press Apply.

The window

/source opens a window beside the drawing with the sheet written out in Heck. It follows the drawing: draw a line and its text appears; pick a face and its line lights up; click a line of text, or drag over several, and those things are picked on the sheet. Right-click a line for Center in view.

Type into it and press Apply: the drawing becomes what the text says. A mistake is marked on its line and nothing changes until it is fixed; Revert puts the text back. As you type it offers words - Ctrl+Space asks for them, /source complete off stops them coming by themselves - and a statement taken from the list comes with its parts to fill in: box = <corner>; <size>.

A place

A place is three lengths and the way each goes, always all three, so the height is there to be seen:

2' east, 3' north, 0 up          on the floor
2' east, 3' north, 4' up         four feet above it
3' west, 2' south, 6" down

east, north and up are the red, green and blue axes; west, south and down go the other way, so no number is ever negative. A place can be said from another: b = a + 4' east, or in a list, to + 4' east. x, y and z are read too, for anyone who prefers them.

Lengths

Written the way a tradesman says them: 4', 2 1/2", 1' 6", 1200mm, 1.2m. A number with no mark is in the sheet's units. Sums are allowed - 4' + 2", (Width - 1') / 2 - and a const block names numbers: Width = 4'.

Faces come from lines

As on the sheet: close a loop of lines and the face appears. So a plain face is never written - a cube is its eight corners and twelve edges, and typing twelve lines that close gives you the six faces. A face is written only when something about it is not automatic: it is painted, it has a hole the lines would not cut, it faces the other way. A loop of lines that is not a face - one you rubbed out - is written noface, so it stays that way.

Box, rect, circle, pull

These are shorthand, not extra things. box = 0 east, 0 north, 0 up; 4' east, 3' north, 2' up reads as the twelve lines and six faces a rectangle pulled up would have made, and a block that is still exactly a box - square, unpushed, no hole, one paint or none - is written that way. Nudge a corner and it is written as its lines again. A circle drawn on a box's top is the box's hole, and the two of them are two lines:

circle c1 = 2' east, 2' north, 4' up; 1'
box = 0 east, 0 north, 0 up; 4' east, 4' north, 4' up

pull is what push/pull makes of any flat outline: its corners, or a circle by name, and how far it went. pull = c1; 2' up is a cylinder.

Blocks and one-liners

One rule covers the grammar: a line with = is complete; a line without one opens a block, and end closes it. The program writes the one-liner when nothing about the thing is unusual and the block when something is - a paint, a width, a name. You may type either.

Names

Corners are named by where they stand - floor1 to floor4 and top1 to top4 on a block, ra1.. round a ring - so line = floor1 to top1 is an upright. A circle is c1, c2. A thing can be given a name - line Rafter, group 'Left eye' - and a name you give is yours; keeping it through the next write is still to come.

Picking points from the sheet

Press Pick and the sheet becomes a point picker: each click, snapped exactly as the line tool snaps, is typed into the line the caret is on - the next <part> if the line has them, or a place, then to and a place for a line, ; and a step for a box, ; and a radius for a circle. Esc on the sheet ends it.

Jigs

A jig - Just Include Geometry - is any program that prints Heck: a batch file, a shell script, Python, Perl, Pascal. A group can be made by one:

group 'Hangers'
  jig = 'hangers' with Count = 6, Spacing = 16", Drop = 4'
end

Jigs live in your own jigs folder beside the program; the drawing names one and never carries it, and nothing runs when a drawing opens - you press the play mark beside the line, or Run jigs for all of them. What the jig printed folds shut under its line. /source sample puts a sample drawing in the window and writes its jigs to the folder for you to look at.

Why text

Two reasons beyond reading it. A drawing that is text is a drawing under git: one statement to a line, so a diff says this corner moved four inches and nothing else, and history, blame and branches come with the tools a programmer already has - a revision browser with a preview of each version is where the source window is heading. And a small, plain language is one a machine can learn from a page: any AI can already write Heck, and anyone can wire their own into it, because nothing in a drawing is hidden.

The rules

  1. It is data, not a program. No loops, nothing executed.
  2. One fact, one place. A line is its two points; its length is whatever that makes it.
  3. Saving loses nothing: what is read back is what was there. Every drawing sent in as a report is checked this way with each build.
  4. Only what differs from the default is written.
  5. One statement to a line, so grep and diff work on a drawing.
  6. A reader skips what it does not know.
  7. A line with = is complete; one without opens a block that end closes.
  8. Faces are what closed lines become.

The full grammar, with what is still to settle, is docs/format2.md in the repository; the set of primitives and the ones still to come are in docs/primitives.md.
