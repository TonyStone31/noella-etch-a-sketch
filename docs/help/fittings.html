The fitting wizard

Duct fittings built from the measurements you took on site.

/transition - also /elbow, /tee or /fitting, whichever word you reach for.

It asks for the measurements a fitter would take, and builds the piece. You are not drawing it; you are describing it.

What it makes

  • A transition - one opening to a different one over a given length. Round to square, big to small, square to offset square.
  • An elbow - a turn, with a throat radius.
  • A tee - a run with a branch off it.
  • An offset - the same size both ends, moved across.

Using it

  1. Pick what kind of fitting it is.
  2. Give it the openings. Round takes a diameter, rectangular takes a width and a height. Type them the way you would write them - 20, 20.5, 8 3/4.
  3. Give it the rest - the length, or the turn and the throat, or where the branch goes.
  4. Build it. It lands in the drawing as a solid.

The tape is worked against the sizes you gave, so the openings have to read before the rest of the fields will.

What comes out

A solid you can push, cut, dimension and export like anything else, and a ticket with the numbers on it. Laying it out flat turns it into a pattern to cut from sheet.
