The etch-a-sketch

The toy this program grew out of, still in it.

/toy. The one button in the corner brings you back.

It started as an etch-a-sketch and the etch-a-sketch never left. Two knobs, a silver screen, and a line you cannot lift - except that you can.

The mouse works too - drag on the screen, or turn the knobs.

Why it is still here

Because it is where the program came from, and because a five-year-old can use it. It is also the only part of this that is purely for fun, which is worth keeping in a program about ducts.
