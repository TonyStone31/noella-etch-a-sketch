Commands

Type a slash and the program tells you what it can do.

How to use it

  1. Type / in the command bar along the bottom - or press the / button at the left of it - and the whole list comes up with a word about what each one does.
  2. Keep typing and it narrows. /re leaves you /rebuild, /rect, /redo, /reface and the rest: the ones that start with what you typed come first, then the ones that merely contain it.
  3. ↑ and ↓ walk the list, the wheel scrolls it, Enter runs what is highlighted, Tab completes the name without running it, Esc puts the list away. Clicking a row does the same as Enter on it.
  4. The ones you have used lately sit at the top and the rest are alphabetical, so it works whether or not you already know the name. It remembers them between sessions.
  5. Beside each name is a word about what it does - and on the row under the pointer, if that command takes something after it, what a real use of it looks like instead. Highlight /scale and the line reads /scale 1/4", which is the bit you would otherwise have come here to find out.

A few worth knowing

  • /holes draws, in red, every edge where a solid is not closed - the answer a slicer will not give you. See solids and 3D printing.
  • /center puts the middle of what is selected on 0,0,0; /tozero stands it on the floor with its near bottom corner there.
  • /units swaps between feet-and-inches and millimetres, /scale 1/4 sets the drawing scale for printing.
  • /cube puts a view cube in the top right of a 3D view. Click a face to look at the model square on, an edge for a half turn between two, a corner for the three-quarter view most drawings are read from - and drag it to turn. It also shows which way you are facing, which the VIEW button cannot. Off until you ask for it, and remembered after that. /cube tl, tr, bl or br puts it in whichever corner suits, and /cube fitselection off stops a click framing what you have picked. With nothing picked it never re-frames: it just goes to the view you asked for.
  • /manual opens these pages.
  • /toy goes to the etch-a-sketch this program began as. The one button in the corner there brings you back.

The list shows one row per action. Most commands have shorter aliases - /e for the eraser, /mv for move - and those all still work; they are in the README rather than the list, because three rows of the same thing would be a worse list.
