Sheets and files

Several drawings in one window, and getting them on and off disk.

Sheets

A drawing can have several sheets, along the top as tabs. They share a window and a file; each one has its own geometry, its own view and its own scale.

  • Ctrl+T, or /new - a new sheet.
  • Ctrl+N - a new sheet with nothing on it.
  • Ctrl+Tab - the next sheet.
  • Ctrl+W, or /close - close this one.
  • /clear - empty this one and keep it.

Use one sheet per thing you are drawing - the part, the assembly, the plan - rather than one file each. They stay together and they print together.

Moving work between sheets

Ctrl+C copies what is picked, Ctrl+X cuts it, Ctrl+V pastes. The paste arrives on the cursor and a click puts it down, so you choose where it lands rather than finding out.

It works across sheets, and that is the point of it: draw a fitting on one sheet, copy it, and put it into the assembly on another. A pasted solid is its own solid - push a face on the copy and the original does not move.

Closing a sheet

A sheet with work on it asks before it goes: save the drawing, close without saving, or keep it open. A sheet nobody has touched does not ask - the example the program starts with arrives with three hundred things on it, and that is not your work to lose.

Closing the window asks the same question if any sheet has work on it.

Saving

  • Ctrl+S - save.
  • Ctrl+Shift+S - save under a new name.
  • Ctrl+O - open.

The file is .hsk, and it is plain text: a line per thing, in feet. You can read it, diff it, and keep it in version control. Nothing in it is compressed or binary.

Through an update

When the program updates itself it has to stop and start again, and it does not make you deal with that. Everything open is written out first - every sheet, which one you were on, and which of them had unsaved work - and put back afterwards exactly as it was, still marked unsaved if it was unsaved. You are told it is going to happen and then it happens.

The draft

Work in progress is written beside the program as you go, so a crash or a power cut does not lose the afternoon. It comes back the next time you start. That is not a substitute for saving - it is one file, and it is overwritten.

Undo

Ctrl+Z and Ctrl+Y, as far back as you like. Undo covers the geometry, not the view - spinning the model is not something to undo.
