The keyboard and the mouse

Every key the program answers to, on one page.

Tool keys are SketchUp's wherever SketchUp has one, because that is the muscle memory worth keeping. Where it does not, the letter is the first letter of the tool. None of them need a modifier: just press the letter.

Select is Space, not S. That is SketchUp's key for the arrow and it is worth the surprise. Esc gets you there as well, once it has finished undoing whatever else is going on, and /s is the short command for it.

While you are drawing

KeyWhat it does
← → ↑ ↓ Before a shape is started, pick the plane to draw on; after it, lock the direction green, red, blue - the same three the rubber band turns
AltBefore a line is started: hold the working plane, and step it round so you can draw in mid air. Esc goes back to following the face under the pointer
AltPart way along a line: step through what the cursor may infer all of them, then the directions off, then parallel and square to the last edge only - SketchUp's cycle. Corners and midpoints keep snapping throughout
AltPulling an arc's bulge: run it out of the edge it started on, smoothly start the arc on an edge first. Alt again lets the cursor pull it
AltWith the offset tool: keep the overlaps a corner taken in further than it is round comes back as it falls, loops and all, instead of being squared off
AltWith rotate or the protractor: free it from the face under the cursor it then turns flat unless an arrow picks a plane
ShiftKeep the axis the move has drifted ontoduring a move or a drag
CtrlLeave a copy behindduring a move. With the eraser it softens an edge instead of deleting it, and Ctrl+Shift brings it back
+ -How many sides a circle or an arc is drawn with or type 24s. With one note picked they are its text size
[ ]Pen thinner, pen thicker
EnterTake what has been typeda length, [x,y,z], <x,y,z> - see typing measurements
EscBack out, one step at a time what is typed, then the shape under way, then the selection, then back to Select
DeleteDelete what is picked with nothing picked it asks before clearing the sheet
