The pipe spool

A run of pipe, leg by leg, from the measurements in your hand.

/spool - also /pipe.

A scratchpad for a pipe run. Click where each leg ends, tell it how long that leg is, and it builds the spool.

Using it

  1. Click where the first leg ends.
  2. Type its length and press Enter.
  3. Click where the next one ends, and so on.
  4. Build it.

Click a leg already in the list to change it, or take it off.

How a length is measured

Each leg says which it is, because a pipe fitter's tape does not measure the same thing twice:

  • end to end
  • end to center
  • center to end
  • center to center

Getting that wrong is how a spool comes back short by two fitting allowances, so it is asked outright rather than assumed.

What comes out

A solid in the drawing, and a cut list with the legs on it.
