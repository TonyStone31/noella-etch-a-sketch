# What we are copying, and where it came from

These are our own notes taken from SketchUp's help pages on 2 September 2026.
They are the spec: when we argue about how a tool should behave, this is what we
argue against.  Each file names its source URL, quotes the rules verbatim where
the wording matters, and ends with a note saying what we have, what we have not,
and where we deliberately differ.

The raw pages could not be archived — help.sketchup.com renders its text in the
browser, so the HTML on disk was empty.  These notes are the reference copy.
